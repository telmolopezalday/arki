# Arki

Aplicaciones de gestión para Limpiezas Arki, la empresa de limpieza de mi familia en Donostia.

Más de 50 personas, más de 100 clientes y cientos de turnos a la semana que se gestionaban en Excel. Arki lo sustituye por dos aplicaciones conectadas a una misma base de datos.

## Escritorio (oficina)
Planificación de turnos, control de horas, tarifas por tipo de cliente, presupuestos y exportación de justificantes y facturas.
